# Dossier Infos — La Géode le Showroom

Toutes les informations collectées pour comprendre l'objectif du nouveau site web.
L'ancien site (lageode66.fr, boutique PrestaShop) a été perdu ; son contenu a été
récupéré via les archives du web (Wayback Machine, snapshots 2021-2022) et complété
par les annuaires en ligne, le registre des entreprises et les réseaux sociaux.
