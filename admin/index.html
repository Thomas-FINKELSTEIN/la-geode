Installateur : connexion par code d'accès GitHub
  1. github.com (compte propriétaire) : Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Nom « Admin La Géode », expiration 1 an, Repository access : Only select repositories → la-geode
  3. Permissions → Contents : Read and write
  4. Une fois connecté, définissez le mot de passe dans « Réglages installateur » en bas de page
