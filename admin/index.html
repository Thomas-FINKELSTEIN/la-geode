Installateur : connexion par code d'accès GitHub
  1. github.com (compte propriétaire) : Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access : Only select repositories → la-geode ; Permissions → Contents : Read and write
  3. Une fois connecté, définissez le mot de passe (menu ⋯ → Changer le mot de passe)
