Installateur : connexion par code d'accès GitHub
  1. github.com (compte propriétaire) : Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access : Only select repositories → la-geode ; Permissions → Contents : Read and write
  3. Une fois connecté, définissez le mot de passe dans « Réglages installateur » en bas

Comment ça marche ?

Votre site est comme votre magasin. Il a 4 grands univers. Dans chaque univers, vous créez des rayons (par exemple « Bracelets »), et dans chaque rayon vous rangez vos articles.

Tout ce que vous ajoutez ici apparaît sur le vrai site, quelques minutes après avoir cliqué « Mettre en ligne ».
