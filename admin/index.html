Collez votre code d'accès GitHub. Il reste enregistré sur cet ordinateur, vous n'aurez pas à le refaire.

Comment obtenir un code d'accès ? (pour l'installateur)
  1. Sur github.com (connecté au compte propriétaire du site) : Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Nom : « Admin La Géode » — Expiration : 1 an
  3. Repository access : Only select repositories → la-geode
  4. Permissions → Repository permissions → Contents : Read and write
  5. Générer, copier le code github_pat_… et le coller ci-dessus
